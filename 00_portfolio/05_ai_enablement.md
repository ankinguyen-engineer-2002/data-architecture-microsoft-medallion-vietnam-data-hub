# AI and Copilot enablement

AI was introduced after the data and semantic foundation, not instead of it.

```text
trusted Gold data
  -> semantic model and measures
  -> governed query contract
  -> Copilot/Data Agent context
  -> bounded agent/tool/flow behavior
  -> evidence-backed response or presentation
```

## Design principles

- Semantic models and approved measures remain calculation authority.
- Prompts improve interpretation; they do not grant access or define truth.
- Tools return source, `as_of`, and `data_quality` evidence.
- Unknown metrics, missing evidence, stale data, and unauthorized scope fail closed.
- Copilot presentation routes are finite and validated.
- Operational automation requires separate identity, approval, idempotency, and receipt gates.

## Maturity boundary

| Surface | Portfolio wording |
|---|---|
| Forecast semantic model | governed analytics contract |
| Adaptive Card chart | bounded live MVP |
| Rich HTML/SVG route | draft/reference implementation |
| Forecast Exception Alert | implementation in progress; runtime blocked |
| AIOS federated runtime | offline/local implementation; live gates open |
| Autonomous ERP/WMS/TMS action | not claimed as deployed |
